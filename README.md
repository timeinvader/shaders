# [IDK]

A lightweight and performance-friendly shader pack.

## Features

*   **Bloom:** Emissive light sources. 

## Compatibility
    Shader writen for old Minecraft version 1.7.10-1.12.2

*   **Angelica:** Supported.
*   **OptiFine:** May working but support is not guaranted

## Status

⚠️ **Work in Progress**
